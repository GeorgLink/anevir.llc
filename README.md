# anevir.llc

Website of Anevir LLC and Georg Link. Plain HTML and CSS: no build step, no tracking, no forms, fonts stored with the site.

## Layout

Everything that gets published is in `docs/`.

| File | What it is |
|---|---|
| `docs/index.html` | Front page: services, Potwin, results, Rendity |
| `docs/about.html` | About Georg: values, roots, family, teammate |
| `docs/terms.html`, `docs/privacy.html` | Legal pages. Edit them directly. |
| `docs/404.html` | Page-not-found page |
| `docs/style.css` | All styles |
| `docs/img/`, `docs/fonts/` | Photos, Rendity screenshots, typefaces |
| `docs/CNAME` | Custom domain for GitHub Pages (`anevir.llc`) |
| `docs/robots.txt`, `docs/sitemap.xml`, `docs/og.jpg` | Search and link-preview files |
| `docs/favicon.svg`, `docs/favicon.png`, `docs/apple-touch-icon.png` | Browser-tab and home-screen icon |

`PRODUCT.md` holds the product notes the design tooling reads. It is not published.

## Publishing with GitHub Pages

1. Push this repository to GitHub.
2. In the repository settings, open Pages and set the source to the `main` branch and the `/docs` folder.
3. Set the custom domain to `anevir.llc` and point the domain's DNS at GitHub Pages.
4. Turn on "Enforce HTTPS" once the certificate is issued.
